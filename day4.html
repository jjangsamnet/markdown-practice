2교시AI와 함께 학급 도구 만들기 — 바이브 코딩

코드를 몰라도 됩니다. 요구사항을 마크다운으로 정확히 쓰는 것(1일차)과 결과를 검증하는 것(3일차)이 여러분의 역할입니다.

요구사항 예시 (모둠 뽑기) — 복사해서 여러분의 도구로 바꿔 쓰세요. 구체적일수록 결과가 좋아집니다.
# 만들 것
초등학교 교실에서 쓸 모둠 뽑기 웹 도구 (파일 하나짜리 HTML)

# 사용자
담임교사가 교실 TV 화면에 띄워 놓고 사용

# 기능
- 학생 이름 24명을 넣어 두면 4명씩 6모둠으로 무작위 배정
- [뽑기] 버튼을 누르면 두구두구 효과 후 결과 표시
- 같은 결과가 다시 나오지 않게 [다시 뽑기] 가능

# 화면
- 글씨는 교실 뒤에서도 보이게 크게
- 알록달록하고 아이들이 좋아할 디자인

# 제약
- 인터넷 없이도 동작하는 단일 html 파일
- 설치나 로그인 없이 더블클릭으로 실행

3부실시간 학급 대시보드 — Firebase 데이터베이스

지금까지 만든 도구는 내 화면 안에서만 동작합니다. 여기에 구글 Firebase 데이터베이스를 붙이면, 학생이 휴대폰에서 누른 것이 교실 TV에 즉시 나타나는 진짜 실시간 도구가 됩니다. (구글 계정만 있으면 무료)

실시간 대시보드 요구사항 예시 — 복사한 뒤 맨 아래에 내 firebaseConfig를 붙여 AI에게 주세요.
# 만들 것
우리 반 실시간 모둠 점수판 (파일 하나짜리 HTML + Firebase Realtime Database)

# 사용자
- 교사: 교실 TV에 대시보드 화면을 크게 띄움
- 학생: 휴대폰·태블릿으로 같은 주소에 접속해 구경

# 기능
- 6개 모둠의 점수를 큰 카드로 표시, 1위 모둠에는 왕관 표시
- 교사 화면의 +1 / -1 버튼을 누르면 접속한 모든 화면에 즉시 반영
- 주소 뒤에 ?teacher=1 을 붙였을 때만 버튼이 보이는 교사 모드
- 전체 초기화 버튼 (교사 모드에만, 누르기 전 확인창)

# 기술 조건 (중요)
- Firebase Realtime Database 사용, 아래 firebaseConfig를 그대로 사용
- 스크립트 태그(CDN) 방식으로 — 설치·빌드 없이 단일 html 파일
- 데이터 구조는 /scores/1 ~ /scores/6 에 숫자 하나씩

# 화면
- 교실 뒤에서도 보이는 큰 글씨, 점수가 바뀔 때 부드러운 애니메이션

# 내 firebaseConfig
(여기에 복사해 둔 firebaseConfig를 붙여넣기)
⚠ 데이터베이스 안전 수칙 — ① 테스트 모드는 30일 뒤 자동으로 잠깁니다. 계속 쓰려면 콘솔의 규칙 탭에서 기간을 갱신하세요. ② 데이터베이스에는 학생 실명·개인정보를 넣지 않습니다 (모둠 번호·별명만). ③ 테스트 모드에선 주소를 아는 누구나 값을 바꿀 수 있으니 학급 밖에 주소를 공유하지 않습니다.
