2교시AI 스튜디오로 학생용 학습 게임 만들기

코드를 몰라도 됩니다. 구글 AI 스튜디오(3일차에 쓴 그 도구)에 요구사항을 정확히 쓰고, 결과를 검증하는 것이 여러분의 역할입니다.

요구사항 예시 (곱셈 게임) — 복사해서 여러분의 게임으로 바꿔 쓰세요. 영단어 게임이라면 "구구단 문제" 부분만 바꾸면 됩니다.
# 만들 것
초등 3학년용 곱셈 연습 게임 (파일 하나짜리 HTML)

# 사용자
학생이 자기 태블릿·컴퓨터로 접속해 혼자 연습

# 기능
- 구구단 2~9단에서 무작위 곱셈 문제 출제
- 정답이면 +10점과 신나는 효과, 오답이면 정답을 보여주고 다음 문제
- 60초 타이머가 끝나면 최종 점수와 등급(예: 곱셈 마스터!) 표시
- [다시 도전] 버튼

# 화면
- 학생 눈높이의 밝은 디자인, 큰 글씨와 큰 버튼
- 점수와 남은 시간이 항상 크게 보이게

# 제약
- 설치나 로그인 없이 동작하는 단일 html 파일

3부실시간 순위 대시보드 — Firebase 데이터베이스

2교시 게임은 내 화면 안에서만 동작합니다. 여기에 구글 Firebase 데이터베이스를 붙이면 학생들의 점수가 서버에 쌓이고, 교실 TV에 실시간 순위표가 나타납니다. 누가 새 기록을 세우면 모두의 화면에서 순위가 즉시 바뀝니다. (구글 계정만 있으면 무료)

실시간 리더보드 요구사항 예시 — 2교시에 만든 게임 코드와 함께 AI에게 주세요. 맨 아래에 내 firebaseConfig를 붙여넣는 것을 잊지 마세요.
# 만들 것 (이어서)
위에서 만든 학습 게임에 Firebase 실시간 순위표(리더보드)를 추가

# 기능
- 게임 시작 전에 별명을 입력 (화면에 "실명 금지" 안내 문구 표시)
- 게임이 끝나면 별명과 점수를 Firebase에 저장
- 게임 화면 아래에 전체 순위 TOP 10이 실시간으로 표시
- 새 기록이 들어오면 접속한 모든 화면에서 순위가 즉시 갱신
- 1위에는 왕관 표시

# 교실 TV 모드
- 주소 뒤에 ?board=1 을 붙이면 순위표만 크게 보이는 대시보드 화면

# 기술 조건 (중요)
- Firebase Realtime Database 사용, 아래 firebaseConfig를 그대로 사용
- 스크립트 태그(CDN) 방식 단일 html 파일 유지
- 데이터 구조: /scores 아래에 {name, score, time} 을 push로 추가

# 내 firebaseConfig
(여기에 복사해 둔 firebaseConfig를 붙여넣기)
⚠ 데이터베이스 안전 수칙 — ① 테스트 모드는 30일 뒤 자동으로 잠깁니다. 계속 쓰려면 콘솔의 규칙 탭에서 기간을 갱신하세요. ② 데이터베이스에는 학생 실명·개인정보를 넣지 않습니다 (모둠 번호·별명만). ③ 테스트 모드에선 주소를 아는 누구나 값을 바꿀 수 있으니 학급 밖에 주소를 공유하지 않습니다.

채점과제 제출 — AI 자동 채점

완성한 게임의 주소를 제출하면 AI가 즉시 채점합니다. 기준: ① 학습 게임의 효과성 40점 ② 필수 요건 30점(Firebase 실시간 연동 + GitHub 서비스 중 — 하나라도 없으면 낙제) ③ 디자인의 적합성 30점. 통과하고 90점 이상이면 완성! 🎉 — 낙제여도 보충해서 몇 번이든 재도전할 수 있습니다.
