# 마크다운 실습실

브라우저에서 바로 실습하는 마크다운 훈련 페이지 모음입니다. 설치나 인터넷 연결 없이 단일 HTML 파일로 동작합니다.

## 구성

| 파일 | 내용 |
|------|------|
| `index.html` | 실습 페이지 목록 (대문) |
| `mission.html` | 기초·중급·고급 3미션 12단계 — 나선형 반복 훈련 |
| `chapter03.html` | 교재 Chapter 03 (09~15절) 연계 11단계 실습 |
| `school-docs.html` | 학교 문서(알림장·가정통신문) 변환 10단계 실습 |
| `mermaid.html` | 머메이드 다이어그램 11단계 실습 (실시간 렌더링, CDN 필요) |

## GitHub Pages로 배포하기

1. 이 저장소의 **Settings → Pages** 로 이동
2. **Source**를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 선택 후 **Save**
3. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 에서 접속 가능

## 사용 방법

- 수강생에게 배포 URL만 공유하면 각자 브라우저에서 실습할 수 있습니다.
- 각 단계의 통과 조건을 모두 만족해야 다음 단계가 열립니다.
- 저장 기능이 없으므로, 남길 답안은 옵시디언 등 노트 앱에 복사하도록 안내하세요.
